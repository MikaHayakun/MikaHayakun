## ENADE ADS · 2026

Um jogo educativo independente para estudar **Análise e Desenvolvimento de Sistemas**, com desafios por fases e apoio de inteligência artificial.

### Jogue e participe

**[▶ Jogar agora](https://enade-ads-2026.vercel.app)** · **[💡 Enviar sugestão](https://github.com/MikaHayakun/MikaHayakun/issues/new?template=sugestao.md)** · **[🐛 Relatar problema](https://github.com/MikaHayakun/MikaHayakun/issues/new?template=problema.md)**

Reconstrua uma cidade digital enquanto pratica lógica, estatística, arquitetura de software, sistemas distribuídos e segurança.

- Comece em **Iniciar missão 1**.
- Acerte pelo menos **4 de 5 desafios** para liberar a próxima missão.
- Escolha entre os modos **leve** e **3D**.

### Contribua com materiais de estudo

No [jogo](https://enade-ads-2026.vercel.app), escolha **Adicionar material** e envie PDF, Word (.docx), Excel (.xlsx) ou TXT, com até **4 MB por arquivo**.

As contribuições passam a integrar o **acervo compartilhado e privado do projeto**, que a IA utiliza para preparar novos desafios para os jogadores. Os documentos não ficam disponíveis para consulta ou download público. Envie somente materiais que você tenha autorização para compartilhar com o projeto.

### Sugestões e problemas

Use os links acima para propor melhorias, comentar a experiência ou relatar dificuldades. É necessário entrar em uma conta do GitHub para enviar sua contribuição.

**As sugestões são públicas.** Não anexe documentos particulares, senhas ou chaves de acesso nas issues. Para contribuir com material de estudo, use exclusivamente o envio dentro do jogo.

## Mikawei — Um tempo para se ouvir

Tem dias em que alguma coisa incomoda, mas é difícil explicar o quê. Talvez você queira falar e nem saiba por onde começar.

O Mikawei oferece perguntas para ajudar você a olhar com mais calma para o que está sentindo e colocar em palavras o que anda confuso. Você pode começar sem ter tudo explicado.

É um espaço de reflexão e autoescuta; não substitui acompanhamento profissional.

**[Quero conhecer o Mikawei →](https://mika-wei-by-legacy-ai.vercel.app)**
